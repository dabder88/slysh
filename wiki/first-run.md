# Первый запуск

Окно «Как расшифровывать» показывается, когда в окружении нет пакетов расшифровки, человек ещё не нажимал «Позже» и не включён режим только облака.

Сохранённый ключ API и Gemini в PATH это окно не закрывают и режим только облака сами не включают.

Три кнопки:

- «Локально на этом компьютере» ставит extras `engine`, `diarization` и `youtube`. Веса модели этим шагом не качаются. Их потом скачивают в Настройках в папку `models` рядом с программой.
- «Через облако» включает режим только облака. Если ключа ещё нет, открываются Настройки. Облако: OpenRouter, Groq, OpenAI, Gladia, Deepgram, свой HTTP, либо Gemini CLI.
- «Напомнить позже» прячет окно до следующего раза.

В установленной копии окна видно, потому что в [[installer]] нет torch. В `.venv` этой папки разработки torch уже есть, поэтому при запуске `Slysh.bat` отсюда окна нет.

`uv sync` без extras на полном окружении снимает torch, GigaAM и NeMo. Бат делает такой sync только если своего `.venv` ещё нет.

См. [[launch]], [[rules]].
