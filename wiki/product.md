# Продовая копия

`F:\ProjectsAI\Slysh-prod` — отдельное дерево Slysh для чужого Windows. Ветка `prod-launch`. Ежедневная разработка остаётся в `F:\ProjectsAI\Slysh` и сюда не слита.

Slysh расшифровывает аудио, видео, микрофон, запись встречи и YouTube. Окно — pywebview и FastAPI. Распознавание локальной моделью идёт в отдельном процессе, чтобы интерфейс не импортировал torch.

В этой копии видимое имя продукта, пакет Python и каталог данных совпадают: Slysh. Слово GigaAM остаётся только там, где речь о самой модели.

Интерфейс настроек — модал с пятью вкладками (ASR, сеть, облако, YouTube, система), см. [[settings-ui]].
