# Запуск

Два разных запуска. Их нельзя путать.

## Из исходников этой папки

Двойной щелчок по `F:\ProjectsAI\Slysh-prod\Slysh.bat`.

Бат выставляет `SLYSH_INSTALL_ROOT` на свою папку и запускает `.venv\Scripts\python.exe -m slysh.app`. Это окружение разработки, в нём уже есть torch, поэтому окно первого выбора пакетов не показывается.

## Уже установленная программа

1. Запустить `F:\ProjectsAI\Slysh-prod\dist\Slysh-Setup.exe`.
2. Если Windows пишет «неизвестный издатель»: «Подробнее», затем «Выполнить в любом случае». Подписи у файла нет.
3. Программа ставится в `%LOCALAPPDATA%\Programs\Slysh` без прав администратора.
4. Дальше открывать ярлык Slysh в меню Пуск. Ярлык запускает `Slysh.bat` в папке установки.

В установленной копии Python лёгкий, без torch. В `{app}\bin` лежат `uv.exe` и `ffmpeg.exe` — отдельно ставить uv не нужно. При первом запуске видно окно из [[first-run]].

Снять установленную копию можно через «Приложения» или `unins000.exe` в папке установки. В начале удаления спросят про папку **models** («Нет» — оставить веса). Данные в `%LOCALAPPDATA%\Slysh` и репозиторий `Slysh-prod` деинсталлятор не трогает.

См. [[installer]], [[data-and-models]].
