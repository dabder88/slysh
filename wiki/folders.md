# Папки

Корень работы — `F:\ProjectsAI\Slysh-prod`. Остальные соседние папки (`Slysh-prod-data`, `Slysh-prod-stage4` и каталог `F:\Slysh-dist`) для продолжения работы не нужны: нужное из них уже скопировано сюда.

| Путь | Зачем |
|------|--------|
| `src/slysh` | Код программы |
| `web` | Интерфейс |
| `Slysh.bat` | Запуск из этой папки и из установленной копии |
| `installer/Slysh.iss` | Скрипт установщика |
| `dist/payload` | Готовый комплект для сборки exe: лаунчер, лёгкий `.venv` без torch, ffmpeg, пустой `models` |
| `dist/Slysh-Setup.exe` | Собранный установщик |
| `.venv` | Окружение разработки с torch. Это не то окружение, которое кладётся в установщик |
| `models` | Веса на машине разработки. В установщик не копируются |
| `bin/ffmpeg.exe` | ffmpeg, который попадает в комплект |
| `wiki` | Эти страницы |
| `docs` | Подробная документация модулей |
| `design/` | Исходники логотипа на машине разработки; в git не входит (в Setup — `web/branding/`) |
| `refs/` | HTML-макеты UI; в git не входит |

`dist` в git не входит. Проводник её показывает. Список файлов Cursor может скрыть.
