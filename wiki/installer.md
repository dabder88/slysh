# Установщик

Файл для человека: `dist/Slysh-Setup.exe`. Скрипт: `installer/Slysh.iss`. Сборщик — Inno Setup, команда `ISCC.exe` с путём к этому скрипту. Пути в скрипте считаются от папки `installer`, комплект лежит в `dist/payload`, результат пишется в `dist`.

## Сборка (разработчик)

1. `powershell -File scripts\build-installer-payload.ps1` — собирает `dist/payload`, качает `bin\uv.exe`, ставит **`runtime\python`** (CPython 3.12 под `{app}`), лёгкий `.venv` без torch.
2. `.\.venv\Scripts\python.exe scripts\smoke_installer_layout.py` — проверка комплекта (build-скрипт вызывает это сам).
3. `powershell -File scripts\build-slysh-setup.ps1` → `dist\Slysh-Setup.exe` (ищет ISCC в `%LocalAppData%\Programs\Inno Setup 6` и Program Files).

`ffmpeg.exe` должен быть в `bin\ffmpeg.exe` в репо или остаться в старом `dist\payload\bin` — иначе build-скрипт остановится с подсказкой.

## Приёмка для любого пользователя

Проверять на **чистом** Windows-профиле или VM **без** Git, без torch и **без** uv в системе — только WebView2 и Setup.exe. Не сравнивать с запуском `Slysh.bat` из репозитория разработки (там torch уже в `.venv`).

| Шаг | Действие | Ожидание |
|-----|----------|----------|
| 1 | Установить `Slysh-Setup.exe` | `%LOCALAPPDATA%\Programs\Slysh`, ярлык **Slysh.exe** (без окна cmd); wizard — язык RU/EN → `.install-ui-locale` |
| 1b | Последний шаг мастера | Галочки «Запустить Slysh» (по умолчанию вкл.) и «Создать значок на рабочем столе» (по умолчанию выкл.); при «Запустить» — сразу `Slysh.exe`, без окна cmd |
| 2 | Пуск → **Slysh** | Только окно программы; `Slysh.bat` в папке — для поддержки, не ярлык |
| 3 | Первый запуск → «Локально на этом компьютере» | Прогресс установки пакетов; в `%LOCALAPPDATA%\Slysh\logs\engine-setup.log` нет «Не найден uv» |
| 4 | Модаль «Модель для распознавания» | Список моделей, «Скачать» (по умолчанию GigaAM) или «Позже» |
| 5 | «Скачать» модель | Файлы в `{app}\models\gigaam`, статус «Готово» |
| 6 | Альтернатива: «Через облако» | Локальное скачивание скрыто; облако настраивается как раньше |

## Состав payload

- `Slysh.exe` — запуск без консоли (ярлык Пуск); `Slysh.bat` — резерв для поддержки
- `installer/prebuilt/Slysh.exe` в git; payload копирует его при сборке
- `src`, `web`, `pyproject.toml`, `uv.lock`
- **`runtime\python`** — CPython 3.12 для uv (`UV_PYTHON_INSTALL_DIR`), не профиль `%AppData%\Roaming\uv`
- лёгкий `.venv` без torch, без пакета модели GigaAM и без NeMo
- `bin/ffmpeg.exe`, `bin/uv.exe`
- пустой `models` (только `.gitkeep`)
- короткая инструкция и тексты лицензий

Не входит: база, `settings.json`, ключи, cookies, записи, скачанные веса, тесты, `.git`.

Почему Python лёгкий: если положить окружение разработки с torch, окно выбора из [[first-run]] не появится, и на чужой компьютер уедет среда этой машины.

Установка: `%LOCALAPPDATA%\Programs\Slysh`, в меню Пуск папка **Slysh** (ярлык программы и удаление), опционально на рабочем столе и запуск с финишной страницы мастера, запись в «Приложениях». **Удаление** снимает `{app}` целиком, в т.ч. `.venv` после установки пакетов расшифровки; **`models/`** по умолчанию удаляется, в деинсталляторе можно ответить «Нет» на вопрос про models, чтобы оставить веса. **`%LOCALAPPDATA%\Slysh`** (база, ключи, логи) не удаляется.

## Обновление установленной копии

Ручная проверка: пункт **«Проверить обновления»** в боковом меню (только если программа установлена из Setup, не при запуске `Slysh.bat` из репозитория разработки).

1. Приложение смотрит GitHub **Releases** публичного репозитория (asset `Slysh-Setup.exe`).
2. Пользователь скачивает установщик и запускает его поверх текущей установки (тот же `AppId`).
3. База `%LOCALAPPDATA%\Slysh` и папка `models` не сносятся. После смены `uv.lock` может понадобиться повторная установка пакетов расшифровки.

Подробно: [docs/features/APP-UPDATES.md](../docs/features/APP-UPDATES.md). Версия в `{app}\version.json` пишется при сборке payload.

Не сделано: подпись, SmartScreen без предупреждения, автообновление в фоне, установка в `Program Files`.
