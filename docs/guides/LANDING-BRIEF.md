# Slysh — бриф для лендинга

Документ для копирайта, дизайна и структуры сайта. Опирается на фактическую стадию продукта (сентябрь 2026) и разбор [COMPETITOR-VIBE.md](COMPETITOR-VIBE.md). Не обещай на лендинге то, чего ещё нет (установщик, macOS/Linux, саммари в один клик и т.д.).

---

## Одна фраза (позиционирование)

**Slysh** — десктоп для Windows: расшифровка речи **по-русски точнее Whisper**, встречи и YouTube без лишней суеты, локально (GigaAM) или через облако, если GPU не тянет.

**Не спорим** с Vibe за «лёгкий Whisper на три ОС». **Спорим** за: русский язык, созвоны, YouTube-пакеты и рабочую библиотеку расшифровок на одном ПК.

---

## Для кого

### Основная аудитория (ICP)

- **Русскоязычные** пользователи **Windows**: журналисты, редакторы, подкастеры, исследователи, аналитики, продакты, юристы, HR, преподаватели, создатели контента.
- Те, кому нужен **не разовый TXT**, а **поток работы**: загрузил → очередь → правка → архив → экспорт → повтор для пакета.
- Те, кто **не хочет бота** в Zoom / Meet / Teams, но хочет текст после созвона.
- Те, кто **обрабатывает YouTube**: одно видео или **канал / плейлист** (субтитры, а не только «скачать и гонять Whisper»).
- Владельцы **NVIDIA GPU** (офлайн GigaAM) **или** готовность платить API (Groq, OpenAI, Gladia, Deepgram, OpenRouter, свой endpoint, Gemini CLI).

### Кому Slysh сейчас не подходит (честно на лендинге или в FAQ)

- Нужен **один клик .exe без Python/uv** — пока запуск из исходников (`Slysh.bat`); установщик в roadmap.
- **macOS / Linux** — только Windows.
- Нужен **максимально лёгкий** офлайн-клиент ~50 МБ (whisper.cpp) без PyTorch — смотреть Vibe и аналоги.
- Нужны **PDF/DOCX/HTML-экспорт, печать, QR с телефона, встроенное саммари** как у Vibe — у Slysh этого пока нет (экспорт: SRT, VTT, TXT, MD; саммари — через внешние LLM в перспективе).
- Нужен **публичный HTTP API для агентов** как у Vibe — у Slysh локальный UI, не продуктовый Swagger.

## Какие цели и «боли» закрывает

| Боль / задача | Как Slysh отвечает |
|---------------|-------------------|
| Плохо слышит русский в Whisper-утилитах | **GigaAM e2e** как основной локальный движок; Whisper — запасной |
| Созвон прошёл — нужен текст, без бота в конференции | **Запись встречи**: системный звук Windows + микрофон, один job, спикеры после стопа (NeMo, опционально) |
| Десятки роликов с канала — вручную нереально | **YouTube-пакет**: список видео, правила, skip completed, дубликаты, экспорт |
| «Сделал расшифровку и потерял» | **Библиотека** в SQLite: очередь, расшифровки, архив, пакеты, фильтры |
| GPU глючит / нет CUDA | **Облачный ASR** и режим **без torch**; ключи в настройках |
| Нужны субтитры, не просто простыня | Редактор **сегментов**, плеер с синхроном, экспорт **SRT/VTT** |
| Долго ждать без обратной связи | **Сегменты в редакторе** во время файловой расшифровки (локально и облако) |
| Приватность | Локально — аудио на своём ПК; облако — только если пользователь сам включил провайдера |
| Диктовка и заметки | **Диктофон** с окнами ~20 с (латентность ожидаема) |

## Основные функции (для блоков «Возможности»)

### Расшифровка файлов

- Аудио и видео (через ffmpeg).
- **GigaAM**, **Whisper / faster-whisper**, облачные провайдеры.
- Очередь jobs, пауза, отмена, повтор.
- Поток сегментов в редактор во время обработки.

### Рабочая библиотека

- Панель, очередь, список расшифровок (файлы и пакеты), архив.
- Редактор: сегменты, спикеры, правка текста, плеер.
- Пакетная обработка файлов с правилами (модель, спикеры, автоэкспорт, задержки, on_error).

### Запись встречи

- WASAPI loopback (звук из Zoom/Meet/Teams и др.) + микрофон.
- Без бота в звонке; одна моно-дорожка (каналы «я/они» раздельно не гарантируются).
- Диаризация после записи при установленном extra NeMo.

### YouTube

- Один URL или **пакет канала/плейлиста**.
- Готовые субтитры (Apify или yt-dlp + cookies), без обязательного прогона Whisper по скачанному аудио.
- Интеграция с библиотекой и пакетными правилами.

### Диктофон

- Запись с микрофона, чанки ~20 с, локально или HTTP STT.

### Облако и гибкость

- OpenRouter, Groq, OpenAI, Gladia (в т.ч. solaria-1 для русского), Deepgram, кастомный HTTP, Gemini CLI.
- Режим **только облако** без локального PyTorch.
- HTTP-прокси для исходящих запросов (STT, YouTube, Gemini).

### Экспорт и постобработка

- **SRT, VTT, TXT, MD** (в т.ч. автоэкспорт пакетов).
- Идентификация спикеров (NeMo MSDD, опционально).

### Интерфейс

- Русский и английский UI.
- Современный десктоп (WebView), без «консольного» UX.

## Преимущества (аргументы «почему Slysh»)

1. **Качество русского** — GigaAM как ядро, а не «ещё один Whisper-клиент».
2. **Два режима мощности** — тяжёлый офлайн (свой GPU) или лёгкий UI + облако.
3. **Встреча как продукт** — сценарий «созвон → текст», не только drag-and-drop файла.
4. **YouTube как конвейер** — каналы и плейлисты в библиотеке, не разовый конвертер.
5. **Станция расшифровщика** — очередь, архив, пакеты, фильтры, повторная работа с job.
6. **Архитектура** — окно без PyTorch; тяжёлый engine отдельно → стабильнее при длинных сессиях.
7. **Прозрачность облака** — пользователь сам выбирает, уходит ли аудио на API.
8. **Русскоязычный контекст** — UI, доки, пресеты (Gladia solaria-1, cookies, Apify).

## Slysh vs конкуренты

### Vs [Vibe](https://thewh1teagle.github.io/vibe/) (главный ориентир)

| Критерий | Slysh | Vibe |
|----------|-------|------|
| Русский ASR | **GigaAM**, сильный офлайн RU | Whisper / др. модели |
| Платформы | Windows | Win / Mac / Linux |
| Установка | Исходники + bat (пока) | Установщик ~42 МБ |
| Облако ASR | **Да**, много провайдеров | Нет как план Б |
| Встреча (loopback + mic) | **Выделенный сценарий** | System audio есть, слабее как продукт |
| YouTube | **Субтитры + пакет канала** | Скачать аудио → Whisper |
| Библиотека jobs | **SQLite, архив, пакеты** | Ближе к file → export |
| Экспорт | SRT, VTT, TXT, MD | + HTML, PDF, JSON, DOCX |
| Саммари / перевод | Пока нет в UI (провайдеры есть) | Claude, Ollama, translate |
| Лёгкий офлайн | Тяжёлый torch или облако | whisper.cpp, Vulkan |

**Сообщение для таблицы на лендинге:** «Vibe — отличный лёгкий Whisper везде. Slysh — когда важны русский, созвоны, YouTube-пакеты и библиотека на Windows.»

### Vs облачные сервисы (Otter, Fireflies, и т.п.)

- Slysh — **локально на ПК**, без обязательной подписки на бота.
- Данные не уходят в облако, **если** выбран локальный движок.
- Нет «умного ассистента встречи» из коробки — фокус на **точном тексте и контроле**.

### Vs Buzz / CLI-скрипты

- Slysh — **единое окно**, библиотека, редактор, пакеты; Buzz — другой продукт (можно переиспользовать диаризацию через env).

## Уникальные отличия (УТП для hero и подзаголовков)

- **«Слышит по-русски»** — GigaAM, не компромисс Whisper-large.
- **«Созвон без бота»** — пишем то, что играет в колонках и микрофоне.
- **«Канал, а не один ролик»** — YouTube-пакеты в той же библиотеке, что и файлы.
- **«Работает, когда GPU капризничает»** — облачный ASR теми же jobs.
- **«Не потеряешь расшифровку»** — архив, статусы, повтор, пакетные правила.

## Черновики формулировок для секций лендинга

### Hero

- **Заголовок (варианты):**  
  - «Расшифровка речи на Windows — сильнее по-русски»  
  - «Slysh: встречи, YouTube и файлы — в одной библиотеке»  
- **Подзаголовок:** Локально на GigaAM или через облако. Без бота в Zoom. Субтитры с канала — пакетом.
- **CTA (сейчас):** «Скачать с GitHub» / «Как установить» (ведёт на FIRST-RUN, не «Download exe»).
- **CTA (после installer):** «Скачать для Windows».

### Social proof (пока без выдуманных цифр)

- Открытый репозиторий, стек GigaAM / проверенные ASR API.
- Сравнение качества RU — осторожно: «GigaAM e2e часто выигрывает Whisper-large в русских side-by-side» (не обещать 70:30 без контекста).

### Блок «Как это работает»

1. Установите окружение (uv + ffmpeg) или позже — один установщик.  
2. Выберите: **локально** (GigaAM) или **облако** (ключ API).  
3. Загрузите файл, запишите встречу или вставьте YouTube.  
4. Правьте в редакторе, экспортируйте SRT/VTT/TXT.

### Блок «Для кого»

- Подкаст и интервью → файлы + спикеры.  
- Стримы и лекции → YouTube-пакет.  
- Ежедневные созвоны → запись встречи.  
- Редакция → очередь и архив.

### FAQ (обязательные честные ответы)

- Нужен ли интернет? — Для локальной модели после установки весов — нет. Для облака и YouTube — да.  
- Куда уходят данные? — Локально остаются на ПК; облако — только выбранный вами провайдер.  
- Mac? — Пока нет.  
- Сколько весит? — Локальный стек с torch — гигабайты; режим «только облако» — без них.  
- Чем лучше Vibe? — Русский, встречи, YouTube-пакеты, библиотека; Vibe — про лёгкость и все ОС.

## Tone of voice

- **Прямой, технически честный**, без «AI magic».
- **На «вы»**, русский по умолчанию; английский UI — для билингвов.
- Подчёркивать **контроль** (локально / облако / архив), не страх.
- Не обещать «мгновенно» для диктофона и встречи — **~20 с** на чанк.
