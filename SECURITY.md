# Security Policy

## Supported Versions

Slysh actively maintains and provides security updates for the following versions:

| Version | Supported |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of Slysh and the privacy of user audio data seriously. Because Slysh is designed as an offline-first desktop application with zero telemetry, vulnerabilities related to local audio capture, subprocess execution, or API key storage are treated with high priority.

If you discover a security vulnerability:

1. **Do not open a public issue** on GitHub.
2. Send an email to the project maintainer: **[dabder@mail.ru](mailto:dabder@mail.ru)**, or reach out privately on Telegram: **[@dabder88](https://t.me/dabder88)**.
3. Include:
   - Type of issue (e.g. command injection, privilege escalation, credential exposure)
   - Steps to reproduce or proof-of-concept (PoC)
   - Affected Windows version and environment details

We will acknowledge receipt of your report within 48 hours and work on a patch before any public disclosure.
