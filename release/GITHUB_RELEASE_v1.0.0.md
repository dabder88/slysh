# Slysh! v1.0.0 — Free Speech-to-Text Workstation for Windows

**Website:** https://slyshai.pro/

## Highlights

- GigaAM + Whisper + optional cloud ASR (Groq, Gladia, Deepgram, OpenRouter)
- Bot-free meeting capture (WASAPI loopback + microphone)
- YouTube channel/playlist batching, SQLite library, export SRT/VTT/TXT/MD
- Installers: Russian and English setup wizards

## Assets
