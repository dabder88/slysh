    Способ получения
    Настройка способа

    Транскрипт получается через облако Apify. Браузер и cookies на вашем ПК не нужны.

    1. Зарегистрируйтесь на apify.com.
    2. Откройте API tokens в личном кабинете.
    3. Создайте токен и скопируйте его.
    4. Вставьте ключ ниже и нажмите «Сохранить».

    Настройка способа

    Бесплатно и локально. Войдите в YouTube в Firefox — приложение возьмёт cookies оттуда. Извлечение доступно только из Mozilla Firefox.

    Настройка способа

    Если вы пользуетесь Chrome, Edge или другим браузером — экспортируйте cookies вручную и загрузите файл сюда.

    1. Установите расширение Get cookies.txt LOCALLY (Chrome/Edge).
    2. Откройте youtube.com и войдите в аккаунт.
    3. Через расширение экспортируйте cookies для youtube.com в файл cookies.txt.
    4. Нажмите «Загрузить cookies.txt» ниже.

    Как расшифровывать

    Выберите, как расшифровывать. Позже это можно сменить в «Настройках».

    Локально на этом компьютере GPU / CPU

    Сразу начнётся загрузка около 3 ГБ — программы распознавания. Лучше видеокарта NVIDIA, на процессоре будет медленнее. Затем можно скачать модель для распознавания.

    Через облако (без нейросетей на ПК) API Keys

    Нужен ваш ключ Groq, OpenAI, Gladia или другого сервиса. Аудио уходит на сервер провайдера, на компьютер пакеты не качаются.

    Выполняется установка uv sync

    Загрузка программ для локальной расшифровки

    Скачиваются библиотеки (PyTorch и др.) — не веса модели речи.
    Обычно 10–30 минут; окно можно не закрывать.
    При включённом VPN загрузка часто «замирает» — на время установки лучше отключить VPN.

    Загрузка может занять 10–30 минут. Окно можно не закрывать.
